# crypto-data

Ежедневный снимок рынка для бумажного крипто-портфеля. GitHub Actions каждое утро в 07:05 по Киеву собирает данные и кладёт их в `data/`; утренний разбор Claude в 07:52 читает их и считает скоринг по точным цифрам.

| Файл | Что внутри | Источник |
|---|---|---|
| `data/indicators.json` | по каждой монете топ-40: цена, изменения 1/7/30 дней, EMA 20/50/200, RSI 14, медвежья дивергенция, ATR, волатильность, сила к BTC; макро и настроения | расчёт по свечам ниже |
| `data/summary.md` | то же, таблицами | — |
| `data/ohlc/<SYM>.csv` | дневные свечи (только закрытые дни, UTC), до 400 дней | Binance (data-api.binance.vision), запасной — Coinbase |
| `data/macro/*.csv` | DXY, S&P 500, NASDAQ, доходность US10Y | Yahoo Finance |
| `data/universe.json` | топ по капитализации, пометки stable / meme | CoinGecko |

Плюс индекс страха и жадности (alternative.me), доминация BTC (CoinGecko), ставки фондирования BTC/ETH/SOL (OKX).
Потоки в ETF здесь нет — бесплатного API у них нет, их разбор ищет в новостях.

Запустить вручную: вкладка **Actions → Daily market snapshot → Run workflow**.
Если какой-то источник не ответил, сбор продолжается, а причина пишется в `errors` в `indicators.json`.

Учебный проект, не финансовая рекомендация.
